# Contributing

Contributions are welcome.

Useful contributions include:
- Compatibility reports for Ragtech UPS models
- Documentation improvements
- Installation fixes
- Automated tests
- NoBrkMon improvements

Please describe the tested hardware, NUT version,
operating system, and relevant behavior.

Do not submit credentials, private keys, IP addresses
from private networks, or sensitive logs.

Code contributions must respect the licenses and
copyright notices of their respective components.
